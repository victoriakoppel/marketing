# Данные ↔ Презентация (ФОТ маркетинга)

Единый источник цифр — **`Данные — структура и ФОТ.xlsx`** (в корне репозитория).
Презентация **`Структура маркетинга — отделы и ФОТ.pptx`** собирается из этого файла.

## Как это работает

1. **Внутри Excel** — всё считается само.
   Меняете число в столбце **«Оклад, ₸»** на листе **«Данные»** → на листе **«Свод»**
   численность и ФОТ по отделам и «Итого» пересчитываются автоматически (формулы `SUMIF`/`COUNTIF`).

2. **Обновить презентацию** из этих данных — пересобрать её одной командой:

   ```bash
   cd build
   pip install openpyxl        # один раз
   npm install pptxgenjs       # один раз
   python3 export_data.py "../Данные — структура и ФОТ.xlsx" deck_data.json
   node gen.js                 # создаст out.pptx
   ```

   Затем скопируйте `build/out.pptx` поверх `Структура маркетинга — отделы и ФОТ.pptx`.
   Или просто попросите меня пересобрать — я запущу это и пришлю обновлённый файл.

## Что можно менять в Excel без правки кода

| Столбец | Что задаёт | Меняется в презентации |
|---|---|---|
| Оклад, ₸ | стоимость позиции | цифра в блоке + ФОТ отдела + «Итого» |
| Позиция (строка 1) | верхняя строка блока | заголовок блока |
| Подпись (строка 2) | ФИО / роль | вторая строка блока |
| Признак = «макс.» | имя не определено | оранжевая цифра со `*` |
| Вакансия = «да» | планируемая позиция | розовый блок |

**Не меняйте столбец «Ключ»** — по нему строка Excel попадает в нужное место слайда.
Добавление/удаление позиций меняет саму раскладку слайда — напишите мне, поправлю вёрстку.

## Файлы

- `make_xlsx.py` — как был создан Excel (обычно запускать не нужно; правьте сам .xlsx).
- `export_data.py` — читает Excel → `deck_data.json`.
- `gen.js` — читает `deck_data.json` → `out.pptx`.
- `render.js` — необязательный предпросмотр слайдов в PNG (нужен Playwright/Chromium).

## Про «живую» связь прямо в PowerPoint

Настоящая связь OLE («Вставка → Связать») привязана к пути файла и требует ручного
«Обновить связи», а между компьютерами часто рвётся — поэтому надёжный вариант здесь
пересборка из Excel (выше). Итоги внутри Excel при этом обновляются мгновенно.
